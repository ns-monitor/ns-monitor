CSV Import Format

Required Header Columns:

Your CSV file should have a header row with 4 columns:

date, time, category, value
Column Specifications:
  • date: YYYY-MM-DD (recommended) or DD/MM/YYYY.
  • time: 24-hour HH:MM. Leave blank or write all-day for timeless notes.
  • category: Note category (e.g. Exercise, Illness, Weight). Matched case-insensitively. Missing categories are automatically created.
  • value: Note description or numeric measurement (e.g. 74.5 for Weight).
Pre-Commit Verification:

Selecting a file will open a preview table showing all parsed rows, duplicate checks, and newly detected categories for your review before committing.
